I had a great time chatting with **Simon Grimm** on the **Rocket Ship Podcast** (Episode 046) about one of my favorite topics: building TV apps with React Native.

## About the Episode

In this episode, we explored the world of TV app development with React Native, diving into the unique challenges and opportunities that come with building for the big screen.

## Key Topics Discussed

### The 10-Foot UI Challenge

One of the biggest differences between mobile and TV development is the viewing distance. TV interfaces need to be designed for the **10-foot experience**:

- Content must be readable from across the room
- UI elements need to be larger and more spaced out
- Visual hierarchy becomes even more important
- Animations should be smooth and purposeful

### Seamless Navigation

Remote control interaction differs significantly from mobile or web apps. We discussed:

- **Focus management** — How to handle focus states and navigation flow
- **D-pad navigation** — Mapping touch interactions to directional controls
- **Platform differences** — How Apple TV, Android TV, and Fire TV handle input differently

### Cross-Platform Development

React Native's promise of "learn once, write anywhere" extends to TV platforms. We talked about:

- Sharing code between mobile and TV apps
- Platform-specific customizations needed for TV
- The current state of React Native TV libraries
- Performance considerations on TV devices

### Fragmentation and Challenges

TV development comes with its own set of fragmentation challenges:

- Different platforms (tvOS, Android TV, Fire TV, Tizen, webOS)
- Varying hardware capabilities
- Different remote control designs
- Platform-specific requirements and guidelines

## My Background

I shared my experience as a Developer Advocate working with devices, mobile apps, and developer communities, and how my background in software engineering, VR, and mobile development shaped my approach to TV app development.
