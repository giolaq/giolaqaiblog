I'm thrilled to announce that my **React Native for TV Workshop** is now live and available at [https://github.com/giolaq/rntvws](https://github.com/giolaq/rntvws)!

## What is This Workshop?

This workshop is a comprehensive, hands-on guide that walks you through building stunning TV apps with React Native. Whether you're a mobile developer looking to expand to TV or just getting started with React Native, this workshop has you covered.

## What You'll Learn

The workshop covers everything you need to know to build production-ready TV apps:

### Remote Control Handling
Learn how to handle navigation and interaction patterns unique to TV:
- D-pad navigation
- Focus management
- Long press and key events
- Platform-specific remote control behaviors

### TV-Specific UI Design
Understand how to design for the "10-foot experience":
- Large-screen layouts
- Focus indicators and highlights
- Content carousels and grids
- Accessibility considerations

### Multi-Platform Development
Build for all major TV platforms:
- **Apple TV** (tvOS)
- **Android TV**
- **Amazon Fire TV**

### Real-World Patterns
Learn patterns used in production TV apps:
- Media playback
- Content browsing
- Search interfaces
- Settings and preferences

## Why React Native for TV?

TV app development has long been fragmented across platforms, each with its own tools and requirements. React Native, combined with TV-oriented libraries, lets you share a large part of your codebase while still handling what's specific to each platform.

The workshop tackles a few of the main challenges:

- Adapting to different input methods, since remote controls vary across platforms
- Keeping content readable on large screens viewed from a distance
- Handling hardware that varies from one TV device to the next
