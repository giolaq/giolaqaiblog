I'm thrilled to announce that my **React Native for TV Workshop** is now live and available at [rntv.giolaq.dev](https://rntv.giolaq.dev)!

## What is This Workshop?

This workshop is a comprehensive, hands-on guide that walks you through building stunning TV apps with React Native. Whether you're a mobile developer looking to expand to TV or just getting started with React Native, this workshop has you covered.

## What You'll Learn

The workshop covers everything you need to know to build production-ready TV apps:

### Remote Control Handling
Learn how to handle navigation and interaction patterns unique to TV:
- D-pad navigation
- Focus management
- Long press and key events
- Platform-specific remote control behaviors

### TV-Specific UI Design
Understand how to design for the "10-foot experience":
- Large-screen layouts
- Focus indicators and highlights
- Content carousels and grids
- Accessibility considerations

### Multi-Platform Development
Build for all major TV platforms:
- **Apple TV** (tvOS)
- **Android TV**
- **Amazon Fire TV**

### Real-World Patterns
Learn patterns used in production TV apps:
- Media playback
- Content browsing
- Search interfaces
- Settings and preferences

## Why React Native for TV?

The landscape of TV app development has long been fragmented across multiple platforms, each with its own ecosystem and requirements. React Native, combined with specific TV-oriented libraries, allows you to share a significant portion of your codebase while still accommodating platform-specific requirements.

The key challenges this workshop addresses include:

- **Adapting to different input methods** — Various types of remote controls across platforms
- **Ensuring readability on large screens** — Viewed from a distance
- **Handling varying hardware capabilities** — Across different TV devices
